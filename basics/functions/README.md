# Fuctions in SQL

These are different from `stored procedures`, as these will not be stored in DB, rather than these are just re-usable functions to perform few actions. These are stored and executed in DB system.

- There are lot of inbuilt functions like `COUNT`, `ROW_NUMBER`, `RANK` etc.
- If those where not sufficient we can use `User Defined Functions`

Procedural Language/PostgreSQL - plpgsql
