# Sub Queries in SQL:

Sub queries are nothing but a query within the Query. Where the inner query will be executed first and the result of the inner query will be passed to outer query. There are different types of queries,

1. Scalar Subquery - Returns the Single value from the Inner Query
2. Correlated Subquery
3. Single row Subquery
4. Multi row Subquery

- SubQueris are written in `()` paranthesis
